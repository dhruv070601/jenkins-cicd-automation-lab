# Jenkins CI/CD Automation Lab

Production-style CI/CD reference implementation demonstrating Jenkins Declarative Pipeline, Docker builds, quality gates, artifact publishing, deployment verification, rollback patterns, and reporting.

## Flow
Git -> Jenkins -> Validate -> Test -> Docker Build -> Quality Gate -> Artifact -> Deploy -> Verify -> Rollback

## Highlights
- Declarative Jenkins pipeline
- Environment promotion controls
- Docker image build
- SonarQube quality-gate integration point
- Nexus/artifact repository integration point
- Python pipeline reporting
- Deployment verification and rollback pattern
- GitHub Actions repository validation

No credentials, internal URLs, company names, or proprietary code are included.
